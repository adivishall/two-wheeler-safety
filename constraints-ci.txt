# Exact-pin constraints for the model-free CI / contributor environment.
#
# `requirements-ci.txt` uses compatible-release (`~=`) ranges so a fresh install
# picks up patch fixes; this file pins the *entire* resolved dependency closure
# to the exact versions the test suite is known to pass on, so CI and a
# contributor's `pip install` are byte-for-byte reproducible instead of drifting
# with each upstream release.
#
# Usage (contributors + CI):
#     pip install -r requirements-ci.txt -c constraints-ci.txt
#
# A constraints file only *pins* versions — it never installs a package that
# isn't also requested — so adding a new dep here is harmless until it's needed.
#
# Regenerate after an intentional upgrade (from a clean venv on Python 3.12):
#     pip install -r requirements-ci.txt && pip freeze | sort > /tmp/frozen.txt
#     # then copy the relevant lines here and re-run the suite to confirm green.
#
# Verified: Python 3.11–3.13, suite green (see docs/INSTALL.md). numpy 2.4
# requires Python >= 3.11, so the pinned test stack does not support 3.10.
