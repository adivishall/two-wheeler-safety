# Plate-to-rider matching: Hungarian vs greedy

- Generated by `python3 evaluate_association.py` (seeds [0, 1, 2, 3, 4], 2000 frames each).
- Layouts: 2-5 riders per frame, width 40-90 px, height 1.8x width, top-left uniform in x 0-600, y 50-300; each rider's own plate present with p=0.85, width 0.6x the rider, offset x -15..+25 px and y -20..+15 px from the rider's bottom edge. Frames with fewer than 2 plates are skipped.
- Same cost matrix for both (`modules/association.py:_plate_body_cost`, default config).
- **Synthetic layouts and a hand-weighted cost; not a field measurement.**

| | greedy | Hungarian |
|---|---:|---:|
| frames with at least one wrong pair | 1703 (18.7%) | 659 (7.2%) |
| wrong pairs / pairs emitted | 3215 / 28946 (11.11%) | 1018 / 28997 (3.51%) |

Frames scored: 9122; the two matchers differ on 1201 (13.2%).

On the shipped synthetic suites (`builtin_scenarios` + crossing scenarios) the matchers differ on 0 of 104 frames with two or more riders and plates, so those suites do not exercise this choice.
